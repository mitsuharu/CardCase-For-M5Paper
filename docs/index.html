CardCase インストーラ

M5Stack の電子ペーパー製品に、ブラウザから直接ファームウェアを書き込みます。

パソコンの Chrome または Edge で開いてください。 書き込みには Web Serial を使うため、iPhone や Android では動作しません。

手順

  1. 本体を USB-C でパソコンに繋ぐ
  2. 画面が消えている場合は電源ボタンを押して復帰させる
  3. 下からお使いの機種のボタンを押す
  4. 表示されるダイアログでデバイスを選ぶ
機種は自動で判別されません。 M5PaperS3 / M5PaperColor / M5PaperMono はいずれも ESP32-S3 で、 ブラウザからは区別がつきません。お使いの機種のボタンを選んでください。

M5Paper v1.1

4.7 インチ / 540 × 960 / フックなし / 側面にロータリスイッチ

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。

M5PaperS3

4.7 インチ / 540 × 960 / 上部にフックあり / ボタンは電源のみ

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。

M5PaperColor

4 インチ / 400 × 600 / カラー表示 / タッチなし・ボタン 3 つ

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。

M5PaperMono

3.97 インチ / 480 × 800 / フロントライトあり / ボタン 2 つ

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。

うまくいかないとき

  • デバイスが一覧に出ない場合は、本体がスリープしている可能性があります。電源ボタンを押してから開き直してください。
  • M5Paper v1.1 は USB シリアル変換（CH9102）を使うため、ドライバが必要な場合があります。
  • 書き込み後に画面が変わらない場合は、SD カードに画像が入っているか確認してください。
